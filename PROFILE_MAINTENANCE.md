# Academic website maintenance

This repository is based on Academic Pages and contains the academic profile of Yuxiao Li.

## Key files

- `_config.yml` — name, avatar, institution, contact details and website URL.
- `_pages/about.md` — homepage and selected publications.
- `_pages/research.md` — projects and research themes.
- `_pages/publications.html` — verified articles and preprints.
- `_pages/teaching.html` — teaching materials.
- `_pages/cv.md` — academic CV.
- `_data/navigation.yml` — site navigation.

## URL and deployment

The current repository is `YuxiaoLee/yuxiao.github.io`, so the anticipated **project site URL** is:

https://yuxiaolee.github.io/yuxiao.github.io/

Enable GitHub Pages under repository Settings → Pages (or use an existing configured workflow).

To use https://yuxiaolee.github.io/ as the user-site URL, rename the repository to `YuxiaoLee.github.io` and set `baseurl: ""`.

Template/demo publications, blog posts, teaching entries, portfolio entries and talks were removed so they do not accidentally appear as real achievements.
